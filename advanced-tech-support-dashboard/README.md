# Advanced Tech Support Operations Dashboard

![Dashboard preview](dashboard-preview.png)

## Executive objective
Give support leaders an interactive view of the ticket funnel, SLA attainment, customer satisfaction, workload patterns, issue drivers, and regional demand.

## Design inspiration
The visual hierarchy is inspired by a modern purple tech-support dashboard reference while the dataset, calculations, workbook, and layout are original portfolio work.

## Advanced capabilities
- Agent-group and priority selectors driving executive KPI cards
- Ticket funnel metrics from created through closed
- First-response and resolution SLA calculations
- Customer satisfaction and open-rate monitoring
- Day-type, topic, product, month, hour, and country analysis
- Conditional formatting for open tickets and response-time risk
- Formula-backed analysis tables supporting native Excel charts

## Deliverables
- Multi-sheet Excel dashboard model
- 600-row synthetic support-ticket dataset
- SQL examples for SLA, workload, topic, and geography analysis
- KPI definitions and targets

## Skills demonstrated
Service analytics, advanced Excel, operational KPI design, SQL, segmentation, SLA reporting, customer-experience analytics, and executive dashboard design.

> All data is synthetic and contains no customer, employee, or employer information.
