# Sales Performance Dashboard

![Dashboard preview](dashboard-preview.png)

## Business question
How are revenue, profit, margin, units, monthly trends, and regions performing?

## Deliverables
- Formula-driven Excel dashboard with native charts
- 144-row synthetic transaction dataset
- SQL examples for monthly and regional analysis
- KPI definitions for auditability

## Skills demonstrated
Excel analytics, KPI design, business storytelling, dimensional analysis, SQL, data visualization.

> All data is synthetic and contains no employer or customer information.
