# Telecom Management Dashboard

![Dashboard preview](dashboard-preview.png)

## Executive objective
Provide telecom leadership with a consolidated view of subscriber growth, churn, service utilization, plan mix, revenue, operating expense, capital efficiency, and net additions.

## Capabilities
- Service-type and plan-type selector controls
- Formula-driven subscriber, acquisition, disconnect, revenue, and churn KPIs
- Monthly subscriber plan-mix analysis
- CAPEX-to-sales efficiency trend
- Text, voice, and data utilization trends
- Gross-versus-net subscriber additions
- Auditable analysis and KPI-definition sheets

## Deliverables
- Multi-sheet Excel dashboard model
- Synthetic monthly telecom dataset
- SQL analysis examples
- High-resolution dashboard preview

## Skills demonstrated
Telecom analytics, advanced Excel, subscriber lifecycle analysis, churn, CAPEX efficiency, network utilization, SQL, KPI design, and executive reporting.

> The design is inspired by the supplied visual reference. All data and calculations are original and synthetic.
