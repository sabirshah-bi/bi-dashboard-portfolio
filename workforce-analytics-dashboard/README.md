# Workforce Analytics Dashboard

![Dashboard preview](dashboard-preview.png)

## Business question
How are headcount, engagement, training, performance, and attrition distributed across the workforce?

## Deliverables
- Formula-driven Excel workforce dashboard
- 165-row synthetic employee dataset
- SQL examples for department analysis
- Auditable KPI definitions

## Skills demonstrated
People analytics, Excel modeling, SQL, KPI design, executive reporting, data visualization.

> All employee records are synthetic and contain no personal information.
